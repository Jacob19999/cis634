## UI behaviour and checks

The page is called Aviation Precedent Explorer. Source scope, common summary search,
source-aware identifiers, AI/source-text provenance, source colours and cross-source
comparison are implemented. Identical coded factor labels within a category are aligned;
per-report coding provenance is preserved, and LLM factors remain separate.

The keyword box searches exported summaries and metadata, not full narratives or a live
embedding service. Cross-source neighbours are semantic, precomputed from narrative vectors.
They are analogues, not confirmed same-incident links. Date/time/place filters narrow the
exported shortlist; source scope does not block the explicit other-source comparison.

Browser checks covered desktop and mobile layouts, both source filters, restoring all-source
search, empty results, source-qualified hash navigation, Escape preserving the selected report,
NTSB and ASRS narrative loading, and a real cross-source comparison. No console errors.
The query `engine failure` matched 2,360 ASRS and 3,980 NTSB reports; source filters correctly
excluded the other collection. These are UI keyword counts, not benchmark metrics.

## Safety analytics follow-up

Added a third Analytics view at `#analytics` in the page repo, implemented in `analytics.js`
and `analytics.css`. It has source/year/keyword/factor filters, stacked yearly report counts,
source-relative factor bars, a phase/event matrix, coding coverage, a reading queue and CSV.
Charts use source-coded factors only; figures are report counts and cohort percentages, not
exposure-adjusted accident rates. Report and map drill-down preserve the exact cohort.

Nine Node tests pass across the search/provenance and analytics suites. Browser checks verified
an NTSB landing/collision cohort of 3,683 reports opening the same map subset, a 2020 NTSB
cohort of 1,268 reports and its prepared CSV link, source report navigation, empty search, and
390 px mobile layout with no horizontal page overflow. A hidden-canvas resize/transition issue
was fixed by stopping animations on Analytics entry and restoring canvas size before map use.
The in-app browser download event timed out; CSV serialisation and the persistent Save CSV
link were verified, but a saved browser download was not confirmed. No dataset or benchmark
changes were needed for this view. These changes remain local and uncommitted.

A further readability fix keeps map region labels above highlighted dots and report links,
uses full contrast during selection and adds dark backing panels and a subtle border. Checked
with a highlighted cohort of 1,508 reports. Screenshots: `cache/safety-analytics.png` and
`cache/highlighted-cluster-labels.png`.

The boxed region-label treatment was subsequently softened at the user's request: no panels
or borders, smaller mixed-case text with a dark text halo, fewer labels at overview scale,
and secondary descriptions only when zoomed in. Labels still render above highlighted dots.
Verified against the 1,508-report cohort; screenshot `cache/subtle-cluster-labels.png`.
